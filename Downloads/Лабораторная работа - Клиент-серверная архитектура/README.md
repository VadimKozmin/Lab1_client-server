Приложение - клиент-серверная архитектура.

Для запуска:

В терминале:
- ps aux | grep mongod - для получения всех запущенных процессов о БД
- kill <PID> - для всех активных процессов БД
- mongod --dbpath /data/db - для запуска БД
- node src/app.js - для запуска проекта сервера и фронтенд-части

В браузере:
- Подключиться к http://localhost:3000/
